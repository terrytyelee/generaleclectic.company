LIQUID API

開口部
An open surface for collaborators, partners, and downstream agents. RESTful access to all systems. Real-time metrics, content feeds, authentication hooks. The artist becomes infrastructure.
GET
/api/v1/artist/metrics
Retrieve real-time metrics across all channels and engagement touchpoints.
Query Parameters
period: 1d | 7d | 30d | custom
platforms: comma-separated list
include: streams,engagement,revenue
POST
/api/v1/content/publish
Orchestrate multi-platform content releases with coordinated timing.
Body Parameters
content_id: string
platforms: array
schedule: ISO8601 timestamp
GET
/api/v1/audience/segments
Access demographic and behavioral audience segmentation data.
Query Parameters
segment_type: geographic,behavioral,tier
depth: basic | detailed
limit: 1-100
POST
/api/v1/collaboration/partner
Create collaboration agreements with partner integrations and webhooks.
Body Parameters
partner_id: string
scope: read|write|admin
webhook_url: string
Integration Example: Fetch Current Metrics
curl -X GET "https://api.general-eclectic.com/v1/artist/metrics" \
-H "Authorization: Bearer YOUR_API_KEY" \
-H "Content-Type: application/json" \
-d '{"period":"7d", "platforms":"spotify,youtube"}'
Example Response
# Returns JSON with current metrics across requested platforms
{
"streams": 2,847,192,
"engagement_rate": 0.084,
"new_followers": 18,420,
"revenue": 42,180.50
}
